Task Discovery Service (TDS)

Centralised mode dashboard and API for inspecting registered services.

Open Dashboard Raw Dashboard HTML API: List Services (JSON)

Quick Start

  1. Ensure the TDS server is running (see demos/centralised)
  2. Build and run this web UI: go run ./pkg/web
  3. Open this page and click "Open Dashboard" to view services

Notes

This UI queries the server-side store for registered services every 5s.
