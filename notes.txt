Peer to Peer mode:
- Create peer-to-peer scaffolding ✓
    -- Runs in client_proxy. When started, if it is not given a bootstrap nodes it starts its own ring. If given a node it registers with it
    -- All nodes known by the bootstrap node are passed on to the new node, any missing or future nodes are discovered when they query / register with the node
    -- Node IDs calculated as a hash of Node's IP address
    -- Due to the more rich commumication of this mode, JSON message structures have been added so changes to messages can be easily managed
    -- When registering a task, task name is hashed and the node finds the node with the closest id to that hash, once found it registers the task with that peer

- Create a method to cope with slow propagation of node discovery ✓
    -- Potential solutions: k-nearest neighbours, node list advertising, querying bootstrap node
    -- k-nearest neighbours: adds redundancy for node loss and copes with propagation issue, needs additional resources for storing duplicate database
    -- node list advertising: periodically send entire node list to all known nodes: ensures that all registered nodes are known however has large overhead with massive data transfer on larger networks
    -- query bootstrap node: with exception of first node, all nodes have a given node that they could query for any changes to node list: will have large impact on bootstrap nodes performance
       in a system with multiple bootstrap nodes it only slightly speeds up propagation
    -- Chosen implementation: k-nearest neighbours as it increases number of nodes that contain task-address mapping for redundancy
       additionally increases likelihood of task mapping being found even if nearest node is not known to the node completing the query

- Cope with loss of nodes and especially bootstrap node [In Progress]
    -- lost nodes currently coped with using k-nearest implementation 
    -- let client be booted with multiple boostrap nodes in case some are offline
    -- handle complete loss of boostrap nodes, is there a way to re-open the circle?
